# Aion-2-DPS-Metr
LegionMate: Умный DPS-метр ,оповещения и многое другое!
Инструмент разработан специально для детального разбора механик, эффективности умений и слаженности групп в подземельях и рейдах.

-—

## Возможности LegionMate (Десктоп-клиент)

- Полная русификация: понятный интерфейс, русские обозначения классов (Гладиатор, Страж, Целитель, Чародей и др.) и корректный перевод всех боевых параметров.
- Запуск в один клик: единый файл программы без необходимости ручной установки сторонних драйверов или библиотек.
- Глубокая аналитика в реальном времени: персональный DPS, урон группы, частота критических ударов, мультиудары и позиционирование (удары в спину/спереди).
- Детальный учет исцеления и поддержки: объемы отхила, HPS и эффективность саппорт-классов.
- Контроль расходки и баффов: отслеживание времени действия еды, свитков отваги/скорости и классовых усилений с точностью до десятых долей процента.
